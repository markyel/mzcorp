# Проверочные скрипты ретрозагрузки

Запускать на сервере от `www-data`, скопировав в `/var/tmp`. Выводят только счётчики, без адресов и текста писем. Базу не меняют.

- `retro-check.sql` — сводка сборки: `sudo -u postgres psql -d MyLift_retro -f retro-check.sql`.
- `retro-onec.sql` — где искать номер 1С у заявок без него.
- `retro-render.php`, `retro-sample.php` — открывают страницы и выборку карточек под разными ролями, проверяют ошибки и очередь.
- `retro-diag.php` — куда попадают документы, что в цепочках поставщиков.
- `retro-final.py` — полнота по индексу замера (`/var/tmp/retro-probe*`): цепочки, 25–27 мая, папки `MZ|`, документы.
- `check-mailboxes.php` — какие ящики подключены и какие в них папки, только чтение.
- `export-memory.php` — выгрузка заметок ассистента в `claude-memory/` с вырезанием адресов и IP: `php export-memory.php <папка памяти> deploy/recovery/claude-memory`.
  После выгрузки просмотреть `git diff`: названия организаций без «ООО», «АО» и подобных скрипт не вырезает, такие правки в копии сделаны вручную и выгрузка их отменяет.
