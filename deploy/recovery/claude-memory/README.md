# Заметки ассистента

Копия личных заметок Claude Code на 05.11.2026, чтобы продолжить работу с другого компьютера. Адреса, IP, организации и ссылки с ключами заменены на `<адрес>`, `<IP>`, `<организация>`, `<id>`. Настоящие значения остались на исходном компьютере и на сервере.

Чтобы новая сессия подхватила их автоматически, скопируйте файлы (кроме этого README) в папку памяти проекта:

```bash
cp deploy/recovery/claude-memory/*.md ~/.claude/projects/<путь-проекта>/memory/
```

`<путь-проекта>` — полный путь к папке проекта, в котором разделители заменены на `-`. Например, `C--Work-mzCorp`. Заметки описывают состояние на момент записи: имена файлов и функций сверяйте с кодом. Заметки о старом сервере Beget относятся ко времени до сбоя.
