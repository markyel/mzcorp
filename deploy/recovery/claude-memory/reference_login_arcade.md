Развлекательная мини-аркада на странице входа (`auth/login.blade.php`, commits eebe0c6→8b11bda, 2026-06-23): свёрнутый `<details>` «Размяться перед сменой» → canvas-игра «Лови заявки» (vanilla JS, без зависимостей), рекорд игрока в localStorage `mzArcadeBest`.

**Текущая механика (мульти-персонаж, commit 8b11bda; +2D-движение 4cd78a0):** ВСЕ сотрудники из ростера ловят падающие ✉; каждый менеджер имеет x И y, роумят в нижней 2D-полосе `[H*0.5 .. H-30]` (игрок ведёт мышью/стрелками по X и Y; AI перехватывают в 2D); ловля по близости `dx²+dy² < (rM+13)²` (можно ловить письма выше пола); ОДНИМ управляет игрок (выбор в пикере «Ты играешь за»), остальные — AI (ловят письма в «своей зоне» по близости — `closestMgr`). Поймал ✉ → менеджер ЗАМИРАЕТ (`freeze`, игрок не двигается; на время заморозки **полупрозрачный** globalAlpha .4 и НЕ ловит ничего — `freeze>0` пропускается в ловле), письмо → ₽ (score++, эмоция **won**) ИЛИ «пустышка» (**lost**), ~62% ₽. Падают также 🚫 **спам** (freeze 54) и 😡 **рекламация** (freeze 96) — эмоция lost, ₽ не дают, ловить плохо. **Граница mzCorp (commit 84b9ea0):** тип письма СКРЫТ (флаг `revealed`) до пересечения `topY` (пунктир «граница mzCorp») — до неё призрачный ✉, после — настоящий тип; кто липнет к границе, ловит плохое ВСЛЕПУЮ → долгий затык; снизу есть запас на реакцию. AI ждёт у центра полосы `(topY+baseY)/2` и уворачивается от опознанного плохого (threat-flee). **Штраф за плохое (commit f549cfe):** поймал спам/рекламацию → `resetToStart` (домашняя колонка `homeX`, низ) вдобавок к заморозке. Игрок двигается ПЛАВНО к цели курсора (`ptx/pty`, `PSPEED 8`), а не телепортом — чтобы откат на старт ощущался (надо доехать обратно). Спавн 70% ✉ / 22% спам / 8% рекламация (commit a3cf081). Изредка (раз в ~12–20с) — редкая 💎 **суперзаявка** (commit ad2b603): медленно падает, золотое сияние + баннер «СУПЕРЗАЯВКА!», ВСЕ AI бросают зоны и преследуют её (`sup` приоритетная цель), поймал → сразу **+10 ₽**; по одной за раз. Раунд-«смена» 45с → лидерборд по закрытым ₽ (игрок подсвечен). Эмоции — 3 варианта аватарки (neutral/won/lost), на проде 6/7 имеют won/lost (фолбэк neutral). Без новых роутов (ростер уже отдаёт карту эмоций) → деплой только blade+view:clear.

**ПУБЛИЧНЫЕ роуты (БЕЗ auth!)** — логин для неавторизованных, штатный `user.avatar` под `auth` тут недоступен:
- `arcade.roster` `/arcade/roster` → JSON `[{id, name(первое слово), url}]` сотрудников с `avatar_neutral_path`.
- `arcade.avatar` `/arcade/avatar/{user}` → отдача neutral-аватарки (только если есть).
- `App\Http\Controllers\LoginArcadeController`. Отдаёт ТОЛЬКО картинку+имя (ничего чувствительного). См. [[user-avatars]].

**Грабли деплоя:** новые роуты → на проде ОБЯЗАТЕЛЕН `route:clear && route:cache`, иначе `route('arcade.roster')` в blade логина → `Route not defined` → **500 на странице входа** (критично — это вход в систему). Новых Tailwind-классов нет (inline-стили) → `npm run build` не нужен. На проде 7 сотрудников с аватарками = 7 героев.
