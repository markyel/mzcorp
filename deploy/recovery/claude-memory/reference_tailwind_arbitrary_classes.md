**Tailwind 4, прод MyLift: НОВЫЕ произвольные значения классов (`w-[112px]`, `h-[78px]`, `max-w-[333px]` и т.п.) НЕ применяются на проде, если их раньше нигде не было.** CSS собран заранее (не JIT в рантайме), деплой = `git pull` + `view:cache` (Blade), БЕЗ пересборки ассетов. Поэтому класс, которого нет в собранном бандле, просто игнорируется → элемент без стиля (картинка показывается натурального размера, ширина не ограничивается и т.д.).

**Симптом:** «сделал миниатюру `w-[112px] h-[78px]`, а картинка полноразмерная» (кейс таба «Поставщики» 2026-06-18).

**Как применять:**
- Для НОВОГО размера/значения в Blade — либо **inline `style="width:116px;height:80px;object-fit:cover"`** (всегда работает, не зависит от сборки), либо **переиспользуй уже встречающийся в коде класс** (напр. `w-[140px] h-[100px]` из таба «Переписка» — он скомпилирован, т.к. используется).
- Обычные (не-произвольные) классы Tailwind (`w-32`, `flex`, `gap-2`) — в бандле есть, работают.
- Если нужен именно новый произвольный класс массово — нужна пересборка CSS на деплое (сейчас в пайплайне её нет).

Связано с [[suppliers-module]] (превью вложений в табе «Поставщики»).
