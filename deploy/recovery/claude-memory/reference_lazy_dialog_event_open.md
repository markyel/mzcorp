**Симптом:** модалка, открываемая из меню/кнопки по событию, открывается ПЕРИОДИЧЕСКИ и/или с большой задержкой. На Windows/Blink чаще работает, на **Mac/Safari** — часто мимо. Кейс M-2026-10119 (меню «⋮» у позиции: 📝 Редактировать / 🔍 Похожие / 🔗 Привязать / 📷 Сменить фото).

**Корень:** диалог — ОТДЕЛЬНЫЙ `lazy` Livewire-компонент со слушателем `#[On('open-…')]`. `lazy` = компонент (и его слушатель) гидратируется только когда попадёт во вьюпорт (IntersectionObserver). Пока не догидратился — open-событие **некому поймать** → модалка не открывается; либо ждёт lazy-подгрузку по сети → «большая задержка». Периодичность = успел/не успел подгрузиться (зависит от скролла/вьюпорта). Safari иначе гоняет observer/вьюпорт → чаще промахивается.

**Диагностический признак:** в том же меню ПРЯМЫЕ пункты (`$wire.method()`) работают, а именно те, что открывают модалку через событие — нет. Значит дело не в вёрстке кнопки, а в доставке события до слушателя.

**Фикс (commit bda719e):** убрать `lazy` у диалогов, открываемых по событию — слушатель `#[On]` регистрируется сразу, открытие детерминированно. Закрытый диалог рендерит пустой `<div>` → eager-стоимость пренебрежима. Файл `resources/views/livewire/requests/detail.blade.php` (item-edit / item-catalog-link / item-photo-rebind).

**Смежное (тоже пробовали, НЕ корень):** сперва заменили Alpine `$dispatch('open-…')` → `$wire.dispatch('open-…')` (commit d9134c8) в `_position-card`/`_item-row` — штатная шина Livewire, надёжнее моста «Alpine DOM-событие → Livewire #[On]». Оставлено, но само по себе НЕ лечило: при lazy слушателя всё равно нет. `open-image` — Alpine-лайтбокс (`x-on:open-image.window`), не трогали.

**ВНИМАНИЕ (латентно, не чинили):** в том же `detail.blade` остальные диалоги (`reassign`, `merge`, `split`, `pause`, `postpone`, `close-lost`, `issue-invoice`, `match-request-item`) — ТОЖЕ `lazy` и открываются по событиям → та же потенциальная грабля. Если пожалуются на их «периодически не открывается» — снять `lazy` так же. Связано: [[floating-composer]], [[duplicated-source-of-truth]].
