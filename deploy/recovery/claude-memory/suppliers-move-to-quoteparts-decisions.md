Заказчик 06.11.2026: вся работа с поставщиками — через QuoteParts, по умолчанию «Внесистемный — запросы через QuoteParts».

- Источник правды — QuoteParts (связь поставщика: профиль, условия, группы, контакты с темами). Раздел «Поставщики» mzCorp — копия; **редактируют в mzCorp, он пишет в QP через API**.
- Постоянный идентификатор поставщика — **код из 1С** (заказчик пришлёт выгрузку). Заменит хрупкие `org:{id}`/`sup:{id}`.
- Запрос цены уходит поставщику, получателя по умолчанию выбирает QP (тема «Расценка»), но в mzCorp нужен **выбор конкретных адресов** (QP уже принимает `targets`).
- Новые адреса из почты — не авторегистрация, а **претенденты с ручным подтверждением** «добавить контакт поставщику».
- Темы контактов — **как в QP** (quoting, finance, logistics, claims, general).
- Профиль: описание ассортимента, бренды, страна, язык, валюта, Incoterms, оплата, срок цены, срок поставки, группы, примечания — согласован.
- **Матрица ассортимента — в QP** (там копится история офферов/отказов).
- **Телефон контакта — добавить в QP** (сейчас в users нет).
- Поставщик-одновременно-клиент — допустимо, переезд это не меняет.

**Сделано 06.11.2026:** этап 1 QP (профиль/условия/матрица/телефон/updated_since/вебхук supplier.updated, QP f1cf0a6); этап 2 — поставщик = организация с `qp_key` (код 1С или `mz:{id}`), `suppliers:onec-bind` (904 поставщика, 862 с кодом); этап 3 — `suppliers:qp-register`, 685 в QP; этап 4 — копия `SupplierMirrorService`, карточка `/dashboard/suppliers/card/{org}`, реестр по организациям, претенденты `supplier_contact_candidates`, слияние `SupplierMergeService`. Дальше — этап 5 (рассылка поставщику с выбором адресов, подбор по матрице), запуск воркера QP, пометка неактивных (ждёт выгрузку закупок 1С).

**Why:** реестр mzCorp (email-строки, ключи из локальных id) разъезжался с QP при слияниях, матрицы утрачены с базой.
**How to apply:** план — сначала доработка QP (API списка/профиля/условий, матрица, телефон, вебхук), потом ключи из 1С, тихая регистрация, перевод рассылки и раздела. Связано: [[supplier-platform-design]], [[quoteparts-git-deploy]].
