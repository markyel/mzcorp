**Где смотреть запросы.** Пользователь ждёт анализ по блоку «Наши фразы → Все фразы» на `/dashboard/direct` = `MetrikaStatsService::phrases()` по таблице `metrika_phrase_stats` (визиты Метрики по фразе+запросу, цели Calltouch/формы; `metrika:pull`). Это РЕАЛЬНЫЕ клики, список маленький (~600 запросов/нед) — разбирать руками. Отчёты Директа (`direct:stats`, таблица `direct_stats`, kind=query, SEARCH_QUERY_PERFORMANCE_REPORT) — это ПОКАЗЫ (11k+ запросов/нед), туда лезть только за кандидатами; LLM-разбор `direct:negatives` (gpt-4o-mini, 200/прогон, вердикт в `direct_query_reviews`, решение за человеком в UI) — медленный, ускорял разовым скриптом срезами по crc32 (`/tmp/judge_slice.php`, 4 потока).

**Кампании (аккаунт, 2026-10):** «Контекст» #714571552 (поиск, самый дорогой клик ~83 ₽), «Склад — запчасти (авто)» #714625809 (НАША, автопубликация из каталога), «Товарная кампания mylift.ru» #714574319 и «Продвижение telegram» #714971577, «Нативная в мессенджерах» — Мастер кампаний: **API минус-фразы НЕ отдаёт и не принимает (null)** → только руками в кабинете. Основной мусор идёт из «Товарной» (автотаргетинг по товарному фиду: аккумуляторы CSB/HR1234W, Mean Well, реле/контакторы/сальники/подшипники → автомобилисты, ИБП, быт); 39% визитов там с неизвестным запросом.

**Как добавлять минус-фразы через API:** `DirectNegativeService::cleanPhrase($p, protectedStems())` (гард: ядро лифт/эскалатор/марки + 4-буквенные основы part_type каталога — «подвесных», «порог», «разъем», «вентилятор», «насоса» заблокированы, т.к. есть в каталоге) → `negatives($cid)` (private, звать через Closure::call) → `campaigns.update` с ПОЛНЫМ списком (перезаписывает целиком, лимит 1000). Директ дедупит по лемме (43 добавил → +37 в счётчике).

**Сделано 2026-10-07:** в «Контекст» (156→193) и «Склад» (145→182) добавлен пакет: авто (нива, урал, камаз, пежо, лада, гранта, террано, прицеп, внедорожник, якорная, машину/машины, соллерс), быт/стройка (входной/входных, квартиру/квартире, бетонные, офисный, для стола, беговой, лестничное, частном доме, амбарной, раздвижных, сдвижной), потребэлектроника (сигнализации, самоката, ибп, фрезера, видеоглазок, netis, erawan, velp), инфо (официальный сайт, что это, какие бывают, посчитать, рассчитать, расчет/расчёт, кабельный завод, пружины сжатия). Сознательно НЕ брал города (клиенты ищут «купить в красноярске») и двусмысленные («по размерам», «подключить», «онлайн»).

**Открытые рекомендации:** (1) в «Склад» голая фраза «комплект» (512 показов, 2 клика: самокат erawan, лабораторный velp) — сузить/убрать; (2) в «Контекст» фраза «Ролик подвеса …» тянет «ролики для подвесных/амбарных дверей» — минус «дверей» в саму фразу (API-гард не даст, слово ядра); (3) в «Товарной» внести руками список авто/быт/электроника.
