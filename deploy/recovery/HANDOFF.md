# Передача работы: восстановление mzCorp

Состояние на **06.11.2026, вечер**, сверено с сервером. Этот файл — точка входа для новой сессии на любом компьютере. Подробности: `RETRO_PLAN.md` (план по этапам), `RETRO_NOTES.md` (находки, правила сборки, грабли), `PLAN.md` (сервер и остальное восстановление). История решений — в `git log`.

Репозиторий **публичный**. IP сервера, адреса сотрудников и клиентов, значения ключей и `CATALOG_SYNC_URL` в него не класть.

## Как продолжить с другого компьютера

```bash
git clone https://github.com/markyel/mzcorp.git
```

```bash
cd mzcorp && composer install
```

Работа идёт в `main`. Уже склонированный проект обновить `git pull`, прежде чем что-либо менять. Соседний проект QuoteParts — приватный `markyel/quoteparts`, клонировать рядом (`../quoteparts`).

```bash
php vendor/bin/phpunit tests/Unit/Retro tests/Unit/QuoteParts tests/Unit/Supplier --no-coverage
```

Проверка не трогает базу. **Весь набор тестов не запускать**: локальный `.env` может смотреть в боевую базу, `RefreshDatabase` её сотрёт (в `TestCase` есть предохранитель, но не надеяться).

- **Сервер:** Reg.ru, выделенный RD-59257, теперь **рабочий** (решение 05–06.11). IP — в панели Reg.ru. Вход `ssh root@<IP>` по паролю; на новом компьютере ключа нет, вход по паролю оставлен намеренно: **не отключать**.
- **Заметки ассистента:** скопировать по инструкции `claude-memory/README.md` (адреса и IP вырезаны).
- **Первое сообщение новой сессии:** «Прочитай deploy/recovery/HANDOFF.md, проверь состояние сервера и продолжим».

## Обязательные правила

- Писем наружу и изменений в ящиках без согласия заказчика не делать. Заказчик подтверждает каждое действие, которое пишет наружу.
- artisan, tinker и git на сервере — только от `www-data` (mzCorp) и `quoteparts` (QuoteParts). Иначе файлы логов создаются под root и воркеры падают.
- Секреты (пароли, ключи) в чат не выводить. Заказчик вводит их сам: `ssh <сервер> "umask 077; cat > /root/.X.tmp"`, Enter, Ctrl+Z, Enter. Перед просьбой убедиться, что прошлый такой ввод завершён.
- Правки с `\App\...` в PHP — через редактор, не `sed`/`perl`. Записи в `.env` заканчивать переводом строки.
- Пользователю — по-русски, коммиты — на английском, conventional, с `Co-Authored-By`.

## Выкладка

**mzCorp** (от `www-data` в `/var/www/mzcorp`): `git pull` → при новых миграциях `php artisan migrate --force` → **`php artisan route:cache`** (маршруты закэшированы: без этого новый маршрут даёт «Route not defined») → `php artisan view:clear` → `php artisan queue:restart`. Конфиг не кэширован.

**QuoteParts** — по `CLAUDE.md` в его репозитории (`git pull`, `composer install`, `migrate`, `npm run build`, `config/route/view:cache`, `supervisorctl restart quoteparts-worker:*`). Коммиты там — с `-c user.name=markyel -c user.email=markyel@users.noreply.github.com` (на этом компьютере git-имя не задано).

Новые Tailwind-классы без пересборки CSS не работают — ширины и сетку в новых шаблонах писать `style="…"`. Плашки: `chip-ok`, `chip-attn`, `chip-info`, `chip-neutral`, `chip-warn`.

## Что работает на сервере

- **База** `MyLift_retro2` (ретросборка + заявки за дни аварии `MZ2026-00001…`). Нумерация новых заявок `MZ{год}-{00000}`. Ночная копия в 03:15 (`deploy/backup/nightly-db.sh`, `/root/backups/nightly`, 14 дней); разовые дампы перед крупными правками — `/root/backups/before-*.dump`.
- **Воркеры mzCorp** (`/etc/supervisor/conf.d/mzcorp-worker.conf`, копия в `deploy/supervisor/`): общий пул 4 + default 1 + каталог 1 + **ботов 1** (очередь `bot` берётся первой). **Cron `www-data`**: `schedule:run` каждую минуту.
- **Режим наблюдения** (с 05.11, `.env`):
  - `ASSIGNMENT_OBSERVE=true` — общий поток info@ не распределяется, в `parsing_meta.assignment_suggestion` пишется подсказка. Назначаются сразу: письмо в личный ящик менеджера или лично ему в копии (`AssignmentService`, `clientChose`), **пересылка из info@ в личный ящик** (`ForwardedToManagerHandler`, только заявкам без ответственного).
  - `MAIL_IMAP_WRITES=false` — система ничего не пишет в ящики (`ImapWriteGuard`).
  - `MAIL_FOLDER_SYNC=true` (включено 06.11) — папки и переносы с Яндекса читаются раз в 10 мин; правки владельца в mzCorp уходят в его ящик.
  - `MAIL_SYSTEM_NOTIFICATIONS=false`, `SUPPLIER_REMINDER_ENABLED=false`, шаблоны уведомлений клиентам выключены.
  - `SCHEDULE_DISABLED` — 19 задач (уведомления клиентам, авто-закрытие, тревоги, IQOT, медиапилот-ретраи и др.; `direct:sync`, `direct:negatives`, `clients:backfill` из списка убраны 06.11).
- **ИИ:** OpenAI только через прокси `ai3.lazylift.ru:8443`; запасной канал — Reg.cloud (`OPENAI_FALLBACK_*`, модель `deepseek-v4.1-flash`, картинки по одной).
- **Настройки из базы пропали вместе с ней** — вернули: автоприменение детектора для КП/счёта/уточнения/отказа (порог 0,85), Директ (см. ниже). Остальное на странице «Настройки» — по умолчанию, при сомнениях спрашивать заказчика.
- **Плашка «Закрыт на реконструкцию»** (`ReconstructionPlaque`) — выключена (`RECONSTRUCTION_PLAQUE=false`); включение и список допущенных — в `.env`.

## Поставщики → QuoteParts (06.11, решения заказчика)

Вся работа с поставщиками — через QuoteParts, по умолчанию «внесистемный — запросы через QuoteParts». QuoteParts — источник правды, mzCorp — копия, **правка в mzCorp идёт в QuoteParts через API**.

- **Поставщик = организация** (`supplier_organizations`), адреса (`suppliers`) — её контакты с темами QuoteParts (`contact_topics`: quoting, finance, logistics, claims, general), порядком, телефоном. Постоянный ключ `qp_key` — **код контрагента 1С** или временный `mz:{id}`; разбор ключа — `SupplierKeys`, смена ключа — `SupplierKeyService`.
- 904 поставщика (862 с кодом 1С, из них 7 ждут выбора кода из кандидатов в карточке; 219 без email — только в mzCorp). 685 тихо заведены в QuoteParts (`suppliers:qp-register`), 1 771 контакт. Названия в QuoteParts — чистые, пометки 1С — в примечаниях.
- Копия: `SupplierMirrorService` — по вебхуку `supplier.updated` и ежечасно (`SyncQuotePartsPoolJob`).
- Раздел «Поставщики» → «Реестр» — список организаций; карточка `/dashboard/suppliers/card/{org}` (профиль, условия, код 1С, контакты, матрица, группы, объединение `SupplierMergeService`). Новые адреса из переписки — **претенденты** (`supplier_contact_candidates`), подтверждает человек.
- Рассылка запроса цены: один представитель от поставщика (первый контакт «Расценка»), получателя выбирает QuoteParts; адреса передаются только отмеченные вручную («все адреса»).
- Матрицы восстановлены у 75 поставщиков из истории запросов (`suppliers:mine-from-outbound --apply`).
- Команды: `suppliers:onec-bind` (привязка к 1С), `suppliers:qp-register`.
